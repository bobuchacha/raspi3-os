# Cursor Assets

This directory holds prerendered custom cursor assets generated by [`tools/make_cursor_assets.py`](/Users/thangcao/CLionProjects/raspi3-os/tools/make_cursor_assets.py).

The sample set emits both the binary `.cur32` asset and a `.png` preview for quick inspection. The default arrow cursor now uses a roomier `32x32` XP-style raster, while the utility cursors remain `24x24`.

Binary layout:

- `CUR\0` magic
- `u32` little-endian `Width`
- `u32` little-endian `Height`
- `u32` little-endian `ActionX`
- `u32` little-endian `ActionY`
- `u32` little-endian `DataOffset`
- `u32` little-endian `DataSize`
- 32-byte NUL-padded UTF-8 `Name`
- 96-byte NUL-padded UTF-8 `Description`
- 32-byte NUL-padded UTF-8 `Author`
- Raw RGBA8888 pixel data

The sample generator currently emits:

- `arrow.cur32`
- `arrow.png`
- `crosshair.cur32`
- `crosshair.png`
- `busy.cur32`
- `busy.png`
